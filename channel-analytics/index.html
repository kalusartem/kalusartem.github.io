Channel Analytics

Channel Analytics is a private, personal tool. Its owner uses it to read statistics for their own YouTube channels.

It runs only on the owner's computer, it isn't offered to anyone else, and it has read-only access: it can't upload, edit or delete anything on YouTube.

It uses two read-only YouTube API scopes:

  • youtube.readonly: list the channel's own uploads (titles, upload filenames, status), so a video isn't posted twice.
  • yt-analytics.readonly: read the channel's view and retention statistics.
