Corsairs of the Archipelago

A browser-based multiplayer age-of-sail game: sail a Caribbean archipelago, trade between colonies, fight broadside battles and board prizes alongside other captains in one persistent world. Plain JavaScript and Three.js on the client, a Node.js + WebSocket server sharing the same game rules, on-demand "seas" so it runs on a free-tier VM, and a strict 60 fps budget on integrated GPUs.
